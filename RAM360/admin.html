Importante para producción

Este HTML nunca debe ser la única barrera de seguridad. Las reglas de Realtime Database deben impedir que un cliente normal lea o modifique licencias de otros clientes. Para validar claves de forma resistente a manipulación, usa una Cloud Function o un backend para la activación y renovación de sesiones.
